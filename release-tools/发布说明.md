# 1.1.19 更新发布

App 版本为 1.1.19，Android 更新编号为 56。覆盖安装需要沿用已安装版本的签名。

配置 push-update.ps1 中的 NAS SSH 地址、账号及新旧公网更新入口。将包含 publish-release.sh 与 release/ 的 TCGshop-POS-release-v1.1.19.zip 放在同一目录。

双击一键发布更新.cmd，在 PowerShell 7 窗口按提示完成 SSH 与 sudo 验证。脚本发布 APK 和清单，并校验公网下载的 SHA-256。

使用 -CheckOnly 校验本地发布包。使用 -VerifyOnly 校验公网清单与 APK。
