# 1.1.2 更新发布

双击“一键发布更新.cmd”，优先使用 PowerShell 7。按终端提示输入 NAS 用户 nasuser 的 SSH 与 sudo 密码。

此版本将 App 更新地址切换至 https://pos.example.com/api/update。旧公网同步地址自动迁移至 https://pos.example.com，保留密钥、账本、账号和同步基线，内网地址保持不变。版本编号为 38，使用原有签名，可覆盖 1.1.1。

只发布 APK 和更新清单，无需重建容器。发布后核对新旧域名清单与新域名 APK 实际下载的 SHA256。旧域名继续提供接口，让旧版 App 能收到此更新。

只校验发布包：pwsh.exe -NoProfile -File .\push-update.ps1 -CheckOnly

只验证发布结果：pwsh.exe -NoProfile -File .\push-update.ps1 -VerifyOnly
