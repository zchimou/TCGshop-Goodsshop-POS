# TCGshop POS 2.0.0

已完成源码回归检查、APK 编译签名及打包资源验证。安装文件：`TCGshop-POS-v2.0.0.apk`。

- 商品与库存列表移除分类列，保留兼容旧账本所需的内部分类数据。
- 手机库存列表使用卡片布局，直接显示售价、成本、库存和操作按钮。
- 经营概览的销售项目明细以所选销售日期内的订单为基础，扣除这些订单截至当前的全部已退数量和退款金额，并扣除分摊优惠。全部退完的商品隐藏；其他订单仍有未退商品时继续汇总显示。
- 销售小票和退款记录继续保留；概览顶部指标仍按销售和退款各自发生日期统计。
- 未定价商品采购入库时填写实际成本，禁止按未设置的售价计算成本比例。
- 修复设置项刚展开后遇到页面重绘而折叠的问题。
- 修复同步等待网络响应时打开编辑窗口，后续同步结果仍可能刷新页面的问题；此时保留编辑内容，等待下次同步。

兼容已部署的 v1.0.14 NAS 服务，不要求因本次界面更新重建服务。

构建入口：项目根目录执行 `powershell -NoProfile -ExecutionPolicy Bypass -File tcgshop-android/build-release.ps1`。
