# 2.0.3 同步提速与后台更新检查

- 无本机修改时携带上次 NAS 版本标识检查；NAS 没变化就只返回 304 状态，不下载、解析或重写完整账本。
- 对同一个地址和密钥，已成功验证的服务信息复用 60 秒。读取服务失败和配置改变会重新验证。
- 新 NAS 服务支持 gzip 下载和上传。App 根据服务能力启用压缩，旧 NAS 和旧安卓桥接继续使用兼容路径。
- 切换页面产生的检查合并，刚同步成功后留出短暂间隔；保存数据及手动同步仍会及时执行。
- 保留同步前快照、并发版本校验、离线记录合并和编辑窗口保护；本轮没有改为增量交易协议。
- 打开和返回 App 时直接显示业务页面，后台检查版本；无新版或自动检查失败不弹出检查页面。发现新版仍显示强制更新窗口。未联网跳过检查，手动入口保留在设置内。

## 部署

推荐在电脑双击同目录「一键更新NAS并发布.cmd」，按提示输入 NAS 密码。该工具上传本次 NAS 更新包，重建原 POS 服务，检查同步提速能力，再发布 2.0.3；保留原 .env、docker-compose.yml 与 data/shop.json。

本次需要升级 NAS 服务，仅运行原「一键发布更新.cmd」只会发布 APK，无法完整启用服务端提速。

也可将 `TCGshop-POS-NAS-update-v2.0.3.zip` 解压合并到 `/vol1/1000/tcgshop-pos-sync`，SSH 执行：

```sh
cd /vol1/1000/tcgshop-pos-sync
sudo sh ./安装更新.sh
curl -fsS https://pos.example.com/tcgshop/api/update
```

版本接口应返回 2.0.3 / versionCode 28。手机可通过更新提示安装，或者手动覆盖安装本次 APK。

## 验证

已验证：无变化 304、服务检查复用、gzip 上传下载、旧 NAS 兼容、身份校验、过期版本拒绝、损坏压缩流拒绝、解压后 20MB 限额、多设备销售退款同步、同步期间编辑保护、多店铺隔离、安卓实际 Java 网络传输类。

本地合成样例约 5.3 KB，压缩后约 1.7 KB；无变化时为一个实际同步请求且账本响应体 0 字节（不计浏览器 CORS 预检）。这不是用户真实网络测速，商品封面仍包含在完整账本中。

APK 沿用原签名。NAS 尚未由助手部署，后台更新检查与系统安装交互仍需安卓真机验证。
