# 蓝牙小票机接入（未打包）

## 选型

- [DantSu/ESCPOS-ThermalPrinter-Android](https://github.com/DantSu/ESCPOS-ThermalPrinter-Android)：Android 原生 ESC/POS 库，提供蓝牙、TCP、USB 连接，MIT 许可。最适合当前 Java + WebView 项目。
- [receiptline/receiptjs](https://github.com/receiptline/receiptjs)：浏览器小票生成与打印方案，连接依赖 Web Serial；当前 Android WebView 使用原生桥接，因此暂不选用。

当前对 DantSu 蓝牙连接类进行了小范围适配，不引入整套排版库。
参考代码固定提交：`f61030e46269319e2d72b938501676420657b9c8`。
来源文件：`escposprinter/src/main/java/com/dantsu/escposprinter/connection/bluetooth/BluetoothConnection.java`。
MIT 许可保存在 `pos/vendor/DantSu-LICENSE.txt`，发布脚本会随应用附带。

适配变化：限定经典蓝牙 SPP，显式选择已配对设备，增加超时关闭、后台任务和分块发送；不使用自动选中第一台设备、不回退到其他 UUID、不申请蓝牙发现或定位权限。
Android 12+ 首次刷新设备或连接时申请附近设备权限，依据 [Android 蓝牙权限说明](https://developer.android.com/develop/connectivity/bluetooth/bt-permissions)。

## 使用流程

1. 在安卓系统蓝牙设置中配对 ESC/POS 小票机。
2. App「数据与设置 → 小票机」刷新已配对设备，选择设备及纸宽，点击连接。
3. 测试打印中文与金额。默认 58mm / 384 点，可改为 80mm / 576 点。
4. 在「销售小票」逐笔点击打印，或打开销售小票详情点击「打印小票」。

连接设置仅存本机，不进入 NAS 同步或账本备份。管理员、店员均可配置当前设备和打印当前店铺已售订单。
若小票机只有 BLE、使用厂商私有协议，或不支持 ESC/POS `GS v 0` 光栅图像指令，则需要另行适配。

## 打印数据和临时样式

每次打印一整笔销售，使用订单快照中的商品名、成交单价、数量、优惠、原实收和销售账号。
如有退款附已退款金额，不修改原销售金额。打印操作不写订单和库存。
当前仅为简版文本测试样式，使用 Android 字体绘制成分段光栅图片，避免中文设备字库差异。
纸宽指常见配置，真实可打印宽度须按具体机型验证。
排版在 `ReceiptRaster.java`，业务取数在 `pos/printer.js` 的 `receipt()`，之后制作样式可独立替换。

发送完成只表示写入连接，不等于机器确认出纸。断开、缺纸及超时可能已部分出纸，必须核实后手动重打；应用不会自动重试打印。
