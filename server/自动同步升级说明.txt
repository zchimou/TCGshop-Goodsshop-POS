示例经营账 v1.4 自动同步升级

先更新 NAS 服务，再更新所有手机。旧手机不能上传新版服务，以避免整本覆盖。
本次文件仅在电脑上生成，尚未部署到 NAS 或腾讯云。

1. 在飞牛中备份原记账项目的 data 文件夹。保留原目录，不要删除容器挂载的数据。
2. 将本压缩包内 server.js、Dockerfile、package.json、docker-compose.yml 更新到原 Docker 项目目录。不要新建空 data 来替换旧数据。
3. 在原项目目录新建 .env 文件，内容：
   SYNC_TOKEN=你自行生成并保存的独立随机长密钥
   建议使用密码管理器生成至少32个英文字母和数字；不要将密钥发到聊天中。
4. 在飞牛 Docker 项目管理中重新构建并启动原项目。若使用终端，在该项目目录执行 docker compose up -d --build。
   保持原来 ./data:/data 挂载路径与 5688:3000 端口。若你原部署有自定义目录或镜像，请保留并同步增加 SYNC_TOKEN 环境变量。
5. 覆盖安装 v1.4 APK，不要卸载旧版。所有使用该账本的设备都需要更新。
6. App 设置中填入已部署的服务器地址及相同同步密钥，点击测试连接，需显示“支持自动同步”。
   外网地址：https://pos.example.com
   若外网代理尚未部署，可先用内网 http://192.0.2.10:5688。
7. 在设置中开启“保存、修改或删除后自动上传”和“打开应用或返回前台时自动同步”。
   开关默认关闭，避免更新客户端后立即向尚未升级的服务端上传。

不同记录自动合并；同一记录不同修改或删除冲突会暂停，保留本机数据。
遇到冲突应先备份各设备数据，再决定是否用手动上传/下载整本替换。
保存后约1秒开始同步；断网保存在本机，恢复网络会重试。
关闭App后不承诺后台上传，下次打开会继续同步。
服务端保存上一版 ledger.json.previous；客户端保存最近一次同步前的本地快照。

重要：旧同步接口没有身份验证，之前的公网代理配置不能单独保护账本。
如果公网入口已启用，请尽快完成本次服务升级和密钥配置。在完成前不要将其当作安全的公网服务。
Nginx 默认会转发 Authorization 与 If-Match，并保留 ETag；如自行修改过代理，需确认这些头未被过滤。
密钥存在手机应用本地存储，请保护设备。更换服务地址后须重新填写密钥。
