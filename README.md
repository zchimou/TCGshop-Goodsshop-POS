# TCGshop POS

示例卡牌店店铺收银与库存管理项目。当前发布版本为 2.0.3。

功能包括商品管理、收银与退款、分店库存、盘库、经营统计、管理员与店员权限、蓝牙小票打印、NAS 数据同步及 App 更新检查。

## 项目目录

- `pos/`：POS 网页界面、业务逻辑和回归检查脚本。
- `tcgshop-android/`：Android 容器、蓝牙打印、更新功能及打包脚本。
- `tcgshop-server/`：NAS 同步服务、Docker 部署及版本发布工具。
- `安装包/`：本地发布工具和版本说明；安装包本体不纳入 Git。
- 根目录页面、`android-app/` 和 `server/`：早期经营账相关代码与资源。

## 构建与部署

Android 构建入口为 `tcgshop-android/build-release.ps1`，需要 Android SDK 和 JDK。脚本中的本机路径需要按构建环境配置。

现有 App 使用的签名密钥位于本机 `android-app/out/debug.keystore`，不会上传到仓库。更新已安装的 App 必须使用原密钥签名，请单独安全保存。版本发布校验还需要本机保留的 `安装包/TCGshop-POS-v2.0.0.apk`。

NAS 部署参见 `tcgshop-server/NAS部署说明.md`；一键发布参见 `安装包/一键发布使用说明.md`。部署脚本包含当前部署环境的地址与目录，迁移环境时需要修改。

仓库不包含实际账本、同步密钥、签名密钥、历史归档、构建缓存和 APK。GitHub 源码备份不能替代业务数据和签名密钥备份。

## 通用源码版本

本仓库已移除原店铺品牌素材和专用部署信息。小票默认不显示头图，可在设置中自行上传。pos.example.com、192.0.2.10 与 nasuser 均为示例配置；请在部署前替换为自己的服务器和账号。此版本的本地存储命名空间已通用化，不可直接覆盖既有品牌版应用以迁移数据。
