# 自提打包与核销

## 使用流程

1. 登录已同步的店员或管理员账号，进入“商品与库存 → 自提订单 → 商品打包”。
2. 选择自提店铺，按商品 SKU 添加商品、填写数量与单价，生成预订单和普通取货二维码。未定价商品需在打包时填写单价。
3. 可保存 PNG 取货凭证，交给顾客。网页版通过浏览器下载，Android 使用系统文件保存界面。
4. 到自提店铺，用收银台“扫码”或商品与库存页“扫一扫”识别取货码。核对商品和实际收款后，点击“已收款，核销并生成小票”。
5. 系统扣减该店库存、生成“自提核销”流水及销售小票，记录核销账号和时间。重复扫码只显示已经核销。

预订单金额与数量不计入当日销售；生成销售小票后才按核销当天统计。核销后的退款使用原有小票退款功能。普通收银保持原有允许负库存规则，自提打包按可预定数量检查，核销时库存不足会拒绝。

## 手动抽奖码

新预订单可填写数字抽奖码，也可留空，生成后在订单详情中补填或修改。空白显示“未分配”，不会自动生成可见抽奖码。跨订单不可重复，取消单仍保留原码。历史订单原码保持不变。网页与 App 1.1.5 显示一致。

网页最近订单与凭证页可取消预订单，确认后释放预定数量、原取货码失效，不改变实际库存或销售。已核销订单不能取消，退款沿用小票退款流程。
