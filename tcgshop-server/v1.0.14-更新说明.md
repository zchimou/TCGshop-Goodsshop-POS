# NAS 更新包（配套 App v1.0.14）

本包用于更新已有 TCGshop POS 同步服务，支持商品售价留空、收款时定价。同步协议仍为 v2。自动同步和多设备合并逻辑在 App 内执行，各设备请覆盖安装 v1.0.14。

## 飞牛 NAS 更新

1. 让各设备暂停收银，确认现有数据已保存。
2. 将 ZIP 解压。把 `server.js`、`sync-core.js`、`Dockerfile` 这三个文件上传到原 POS Docker 项目目录，覆盖同名文件。你之前使用的目录是 `/vol1/1000/tcgshop-pos-sync`；请先确认该目录内有原来的 `docker-compose.yml` 和 `.env`。
3. 保留原 `data` 目录、`.env`、`docker-compose.yml`，无需修改同步密钥、端口或外网地址。本更新包不包含这些文件。
4. 在飞牛 Docker 的原项目中执行重新构建并启动。若使用 SSH，在 NAS 主机终端执行下面的命令，不要在容器内部终端执行。

```sh
cd /vol1/1000/tcgshop-pos-sync
sudo docker compose up -d --build
sudo docker compose ps
```

确认服务状态为 `Up`。可用以下命令确认新校验代码已进入容器；该命令不读取账本或密钥：

```sh
sudo docker compose exec -T tcgshop-pos-sync node -e "const fs=require('fs');const s=fs.readFileSync('/app/sync-core.js','utf8');if(!s.includes('!num(p.price)')||s.includes('!num(p.price,1)'))process.exit(1);console.log('PASS: v1.0.14 未定价商品支持已安装')"
```

5. 打开新版 App，在设置中测试连接，再点击右上角同步。各设备均升级后再使用售价留空功能。

容器显示 Up 只表示已启动，仍需完成上面的版本代码检查和 App 同步测试。本包已在电脑生成，尚未上传或部署到 NAS。

如果原项目目录、Compose 服务名被你修改过，应使用实际目录和服务名。不要新建空数据目录或执行删除数据卷的命令。
